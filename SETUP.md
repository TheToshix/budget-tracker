# Инструкция по установке и запуску

Подробный пошаговый гайд, как превратить код из `src/` в реально
запускающийся проект на своём компьютере и задеплоить его. Рассчитан
на то, что раньше вы этого не делали — каждая команда объяснена.

Если что-то из терминологии непонятно (что такое npm, зачем нужен
Vite и т.п.) — не страшно, это всё объясняется по ходу.

---

## Что понадобится

1. **Node.js** — среда для запуска JavaScript вне браузера. Через неё
   ставятся все инструменты сборки.
   Скачать: https://nodejs.org — версия **LTS** (не «Current»).
2. **Редактор кода** — например, [VS Code](https://code.visualstudio.com/) (бесплатный).
3. **Терминал** — на macOS/Linux это стандартный Terminal, на Windows
   лучше всего [PowerShell](https://learn.microsoft.com/ru-ru/powershell/) (уже встроен) или терминал внутри VS Code
   (`` Ctrl+` ``).
4. Аккаунт на **GitHub** (нужен на последнем шаге, для деплоя) —
   опционально, если пока просто хотите запустить локально.

Проверить, что Node.js установился, — в терминале:

```bash
node -v
npm -v
```

Обе команды должны напечатать номер версии (например, `v20.11.0` и
`10.2.4`). Если пишет «command not found» — Node.js не установлен или
нужно перезапустить терминал после установки.

---

## Шаг 1 — Создать проект на Vite

Vite — инструмент, который берёт ваш код на React и превращает его в
файлы, понятные браузеру, плюс даёт локальный сервер для разработки
с мгновенным обновлением страницы при изменении кода.

В терминале перейдите в папку, где хотите создать проект, и выполните:

```bash
npm create vite@latest budget-tracker -- --template react
```

Если спросит что-то вроде «Ok to proceed? (y)» — отвечайте `y` и Enter.

После этого:

```bash
cd budget-tracker
npm install
```

`npm install` скачивает и устанавливает базовые зависимости проекта
(React и сам Vite) — это может занять минуту.

Проверьте, что всё работает:

```bash
npm run dev
```

Терминал напечатает что-то вроде `Local: http://localhost:5173/`.
Откройте эту ссылку в браузере — должна открыться стартовая страница
Vite + React со счётчиком кликов. Если видите её — всё в порядке,
останавливайте сервер (`Ctrl+C` в терминале) и переходите дальше.

---

## Шаг 2 — Скопировать код приложения

1. Откройте папку `budget-tracker` (только что созданную) в VS Code.
2. Внутри неё найдите папку `src/` — там будут файлы `App.jsx`,
   `index.css`, `main.jsx` и папка `assets/`.
3. **Удалите** из этой `src/` всё, кроме `main.jsx` (его не трогаем).
4. Скопируйте **содержимое** папки `src/` из этого чата (`App.jsx`,
   `constants.js`, `components/`, `hooks/`, `utils/`) внутрь папки
   `src/` вашего нового проекта — так, чтобы получилось:

```
budget-tracker/
├── src/
│   ├── main.jsx          ← оставили как было
│   ├── App.jsx            ← из этого чата
│   ├── constants.js       ← из этого чата
│   ├── components/        ← из этого чата
│   ├── hooks/              ← из этого чата
│   └── utils/               ← из этого чата
├── index.html
├── package.json
└── ...
```

5. Также скопируйте `storage-adapter.example.js` в `src/utils/storage-adapter.js`
   (без `.example` в названии — так удобнее подключать).

---

## Шаг 3 — Подключить адаптер хранилища

Приложение обращается к `window.storage` — API, который существует
только внутри Claude Artifacts. В обычном браузере такого объекта нет,
поэтому нужно один раз «подложить» свою реализацию поверх
`localStorage` (постоянное хранилище прямо в браузере пользователя).

Откройте `src/main.jsx` и добавьте в самое начало файла, до всего
остального:

```jsx
import { createLocalStorageAdapter } from "./utils/storage-adapter.js";
window.storage = createLocalStorageAdapter();
```

Файл целиком должен выглядеть примерно так:

```jsx
import { createLocalStorageAdapter } from "./utils/storage-adapter.js";
window.storage = createLocalStorageAdapter();

import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import "./index.css";
import App from "./App.jsx";

createRoot(document.getElementById("root")).render(
  <StrictMode>
    <App />
  </StrictMode>
);
```

## Шаг 4 — Установить недостающие зависимости

Приложению нужны две библиотеки, которых нет в чистом Vite-проекте:
`recharts` (график) и `lucide-react` (иконки).

```bash
npm install recharts lucide-react
```

---

## Шаг 5 — Подключить Tailwind CSS

Компоненты используют классы вроде `flex`, `text-sm`, `rounded-full` —
это Tailwind CSS. Самый быстрый способ подключить его для локального
запуска — через CDN, без отдельной настройки сборки.

Откройте `index.html` в корне проекта и добавьте внутрь `<head>`:

```html
<script src="https://cdn.tailwindcss.com"></script>
```

Это самый простой вариант для учебного/демо-проекта. Если планируете
деплоить в production, лучше подключить Tailwind «по-настоящему» —
через `npm install -D tailwindcss postcss autoprefixer` и конфиг —
но для запуска и демонстрации портфолио CDN-варианта достаточно.

---

## Шаг 6 — Запустить и проверить

```bash
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`).
Должно открыться приложение — гроссбух с формой добавления записи.

**Проверьте:**
- добавляется расход и доход;
- после перезагрузки страницы (`F5`) данные не пропадают — значит,
  адаптер хранилища из Шага 3 подключился правильно;
- переключается тема в настройках;
- открывается меню кошельков.

Если что-то не работает — см. раздел «Частые проблемы» ниже.

---

## Шаг 7 — Собрать production-версию

Когда всё проверено локально, соберите финальные файлы для деплоя:

```bash
npm run build
```

Появится папка `dist/` — это и есть готовый статический сайт: набор
HTML/CSS/JS файлов, которые можно разместить на любом хостинге.
Проверить сборку локально:

```bash
npm run preview
```

## Шаг 8 — Выложить в интернет (по желанию)

Самый простой вариант — **Vercel** (бесплатно для личных проектов):

1. Зарегистрируйтесь на https://vercel.com через GitHub-аккаунт.
2. Залейте проект на GitHub (см. ниже, если ещё не делали).
3. На Vercel: «Add New… → Project» → выбрать репозиторий → Deploy.
   Vercel сам определит, что это Vite-проект, и всё соберёт.

Альтернативы: Netlify (аналогично Vercel) или GitHub Pages
(потребует чуть больше ручной настройки `vite.config.js` — при
необходимости, спросите отдельно, распишу шаги под GitHub Pages).

### Как залить проект на GitHub, если ещё не делали этого раньше

```bash
git init
git add .
git commit -m "Первый коммит: Budget Tracker"
```

Дальше на github.com создайте новый пустой репозиторий (кнопка
«New repository», без README/gitignore — они уже есть локально), затем:

```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/budget-tracker.git
git branch -M main
git push -u origin main
```

Не забудьте закинуть в репозиторий и остальные файлы из чата —
`README.md`, `BUG-REPORTS.md`, `TEST-CASES.md`, `CHECKLIST.md` — они
как раз и превращают репозиторий в портфолио-проект, а не просто код.

## Частые проблемы

**«command not found: npm»**
Node.js не установлен или терминал не видит его после установки —
закройте и откройте терминал заново, при необходимости переустановите
Node.js с https://nodejs.org.

**Белый экран в браузере, в консоли (`F12` → Console) ошибка импорта**
Скорее всего, при копировании файлов из Шага 2 нарушилась структура
папок — проверьте, что `components/`, `hooks/`, `utils/` лежат ровно
внутри `src/`, на одном уровне с `App.jsx`.

**Данные пропадают при перезагрузке страницы**
Проверьте Шаг 3 — `window.storage = createLocalStorageAdapter()` должен
выполняться **до** рендера `<App />`, то есть быть в самом начале
`main.jsx`.

**Стили не применяются, всё выглядит «голым» HTML без вёрстки**
Проверьте Шаг 5 — тег `<script src="https://cdn.tailwindcss.com">`
должен быть внутри `<head>` в `index.html`, а не где-то ещё, и
интернет-соединение должно быть доступно (CDN грузится из сети).

**Ошибка `Module not found: recharts` или `lucide-react`**
Значит Шаг 4 не выполнен или прошёл с ошибкой — выполните
`npm install recharts lucide-react` заново внутри папки проекта.

**После `git push` просит логин/пароль, а пароль не принимается**
GitHub больше не принимает обычный пароль для `git push` — нужен
Personal Access Token (создаётся в GitHub: Settings → Developer
settings → Personal access tokens) или настроенный SSH-ключ. Это
отдельная тема — если понадобится, могу расписать по шагам отдельно.

Если на каком-то шаге что-то пойдёт не так — просто опишите, что
видите в терминале или в браузере, разберём вместе.
