# Regression Checklist — Budget Tracker

Быстрый чек-лист для прогона перед демо/релизом (5–10 минут). Полные
тест-кейсы с шагами и ожидаемым результатом — в `TEST-CASES.md`.
Полный список правил приёмки для найденных дефектов — в `BUG-REPORTS.md`.

## Кошельки
- [ ] Создание кошелька с валютой
- [ ] Создание кошелька с уже занятым именем → ошибка, не создаётся
- [ ] Переключение между кошельками не смешивает данные
- [ ] Суммы форматируются в валюте текущего кошелька

## Категории
- [ ] Добавление новой категории (имя + цвет)
- [ ] Добавление категории с уже занятым именем → ошибка
- [ ] Переименование категории, пустое имя не сохраняется
- [ ] Смена цвета применяется во всех местах (список, график, точки)
- [ ] Удаление категории с расходами → расходы становятся «Без категории», а не пропадают

## Записи (расходы/доходы)
- [ ] Добавление расхода
- [ ] Добавление дохода
- [ ] Сумма 0 / отрицательная → отклоняется с сообщением
- [ ] Полное редактирование записи (дата/тип/категория/описание/сумма)
- [ ] Удаление записи
- [ ] Поиск по описанию работает
- [ ] Фильтры (категория/тип/диапазон дат/превышение бюджета) работают и сбрасываются

## Бюджет и остаток
- [ ] Редактирование лимита категории, Enter/Escape/blur ведут себя ожидаемо
- [ ] Прогресс-бар и цвет превышения корректны
- [ ] «Остаток бюджета» и «Баланс месяца» пересчитываются при любом изменении

## Финансовые цели
- [ ] Добавление цели
- [ ] Редактирование накопленной суммы (с подтверждением, если включено)
- [ ] Удаление цели
- [ ] Прогресс-бар и % отображаются верно, цель у 100%+ выделяется

## Регулярные операции
- [ ] Добавление шаблона
- [ ] Баннер предлагает применить операцию за текущий месяц
- [ ] Применённая операция не предлагается повторно в том же месяце
- [ ] Удаление шаблона

## Аналитика и график
- [ ] График по месяцам отражает 6 последних месяцев от просматриваемого
- [ ] % изменения к прошлому месяцу считается верно
- [ ] Топ-3 категории и «самый дорогой день» совпадают с данными

## Данные
- [ ] Экспорт JSON скачивается и открывается
- [ ] Импорт валидного JSON заменяет данные (с подтверждением)
- [ ] Импорт невалидного файла → понятная ошибка, данные не портятся
- [ ] Экспорт CSV содержит все операции текущего кошелька

## Настройки
- [ ] Переключение светлая/тёмная тема применяется сразу
- [ ] Тема и настройка подтверждений сохраняются после перезагрузки
- [ ] Переключатель подтверждений реально включает/выключает диалоги

## UI / доступность
- [ ] Клик вне выпадающего списка кошельков/панели настроек закрывает их
- [ ] Все интерактивные элементы доступны с клавиатуры (видимый focus)
- [ ] Мобильная раскладка (~375px) без горизонтального скролла
- [ ] Длинные названия/описания усекаются, не ломают вёрстку

## Персистентность
- [ ] Данные сохраняются после перезагрузки страницы
- [ ] Повреждённые данные в storage не приводят к белому экрану
- [ ] Быстрая серия правок подряд не теряет и не дублирует данные
